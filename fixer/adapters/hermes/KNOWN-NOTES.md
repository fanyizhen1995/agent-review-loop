# Hermes 适配器限制

- 同一 Hermes home 共用受管脚本、审批和委派配置，不同项目不得覆盖；使用独立 home/profile。
- 安装器使用标准库合并有限 YAML 结构；重复受管键、复杂嵌套和别名会明确失败。
- 正式安装需核对 Hermes cron CLI 的帮助和 JSON 结构，未知形式停止。
- 列表数量限制、评论排序和删除失败记录需在项目实际规模下核对。
- GitHub token 到期时间不能统一查询，应自行记录并续期。
- 公共 deny 之外的项目命名空间和禁止分支需检查全部命令形式；不能绕过拒绝。

离线测试不访问远端，真实身份、保护规则、模型与业务冒烟由项目部署流程验证。
