# 自动合入与登记设计记录

自动合入由轮询定时程序处理，登记使用独立 cron。两者通过进程内受限权限上下文开放写操作，评审 CLI 和执行方保持原有权限边界。

合入使用成员最近的有效同意或撤回、评审状态、冲突状态及当前 HEAD。冲突交回执行方追加修复；合入成功先保存通知状态，通知失败下轮补发。

登记读取目标分支快照，按稳定条目标识去重，一次提交全部受管文件。通用 changelog 或项目 hook 由 workflow.register 选择，hook 只允许修改显式白名单内的文件。目标分支变化或 API 失败时停止，后续轮次重试。

离线验收覆盖 forge 请求、权限、幂等、并发失败和 dry-run。真实成员可见性、分支保护、合入及推送权限、cron 时区在项目部署环境中验证。
